# Aditi & Samrat — Premium Animated Wedding Invitation V6

This is the complete HTML/CSS/JavaScript build.

## Typography
- Bodoni Moda — dates, time, large date numerals
- Pinyon Script — Aditi, Samrat, Mehendi, Sangeet, Haldi, Wedding
- Cormorant Garamond — body text, taglines, venue, attire, RSVP

## Motion
- Swipe-to-open intro
- Smooth gate exit and invitation entrance
- Lotus blessing shower using the supplied lotus asset
- Reversible scroll reveal animations: content animates in and out as sections enter/leave
- Staggered typography animation for blessing/event blocks
- Smooth cloud, moon, waterfall, damru, Nandi, Shivling and Shiva-Parvati motion
- Reduced-motion accessibility support

## Mobile priority
The design is optimized for 320–450px wide mobile screens. Desktop centers the same invitation composition.

## Run
Open `index.html` directly, or serve the folder with:

python -m http.server 5500
